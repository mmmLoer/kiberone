# Аудит KIBERone — 08.10.2026

## Исправления

- Привязка запросов и WebSocket ученика к постоянному случайному секрету устройства. Тьютор сохраняет привязку; подмена идентификатора в теле или URL отклоняется.
- Синхронизация разрешает только операции из согласованного плана. Восстановление, загрузки и удаления сериализованы для проекта; обход каталога через ссылки запрещён.
- Сервер отклоняет перенос идентификаторов учеников и групп между локациями.
- Выход ученика очищает активную сессию даже после ошибки сохранения. Исправлены гонки смены группы и получения почты, чтение письма одновременно с его удалением.
- Исправлены переходы файл/каталог и откат Git-восстановления.
- Установка останавливает VPN-службу до замены файлов. Рабочий ПК не использовался для включения VPN.
- CI повторяет сборку после неудачи на том же коммите, сериализует запуски и публикует неизменяемые артефакты с атомарной заменой манифеста.
- Обновлены зависимости SQLite, D-Bus и тестов. Проверка NuGet не обнаружила известных уязвимых пакетов.
- Стандартный адрес Hub переведён на HTTPS с сохранением совместимости хранилища учётных данных. Настроен nginx на nshub.pro.
- Hub с отключённой почтой больше не меняет права каталога отдельного почтового сервиса. При обнаружении ошибки запуска обновление автоматически откатилось; после исправления повторное развёртывание успешно.

## Ограничения и оставшаяся проверка

Обе VM находились на экране входа; GuestControl запускал процессы без административного токена. Поэтому не подтверждены нативные окна, чистая установка с UAC, блокировка экрана, watchdog, работа VPN и полный обмен между двумя VM через LAN. Автоматические и файловые тесты не заменяют эти проверки. Для продолжения нужно войти в Windows на VM и установить свежую сборку с правами администратора.

Первичная привязка устройства использует TOFU: первый контакт должен происходить в доверенной сети. Секрет устройства не доказывает личность выбранного ребёнка. Локальный HTTP не защищает от перехвата трафика; серверные API используют HTTPS.

Старый Student несовместим с новым защищённым Tutor. Сначала обновить Student установщиком, затем Tutor. Секреты устройств сохранять при переустановке и не клонировать между ПК. См. `device-identity.md`.

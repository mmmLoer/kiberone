# Перенос макета в приложения

Перенесены экраны Figma T15–T18 и S11–S12: доступ класса, каталог приложений с иконками, правила сайтов, отдельный VPN Tutor, почта ученика и чтение писем. История версий проектов перенесена ранее.

## Доступ класса

Tutor → Доступ класса → выбрать группу → настроить приложения/сайты → включить правила → опубликовать. Правила сохраняются в базе группы, включаются в экспорт локации и передаются Student через heartbeat. Новые ПК получают ту же политику после входа ученика.

Student отправляет каталог App Paths и открытых приложений каждые две минуты. Иконки передаются в PNG. Это не полный реестр всего установленного ПО.

Сайты ограничиваются пользовательскими политиками Chrome и Edge. Политики применяются с задержкой обновления браузера; другие браузеры не контролируются. Student удаляет только свои значения политик при завершении и восстанавливает очистку при следующем запуске после аварии. Изменения, уже загруженные браузером, тоже исчезают после обновления его политик. Это инструмент управления занятием, а не защита от намеренного обхода пользователем.

## Почта

Student → Почта: адрес и скрытый пароль с копированием, входящие, текст письма, найденный числовой код, пользовательский список HTTPS-сервисов. Пароль генерируется сервером один раз для GUID ученика. Список сервисов пока хранится отдельно для ученика на текущем ПК; сообщения не помечаются прочитанными, вложения не показываются.

Почтовый API развёрнут 7 октября 2026 отдельной службой на 193.182.145.64. HTTPS: https://nshub.pro/api/mail/. Существующий Hub и портал работают отдельно. Для выдачи ящика Tutor нужен пароль локации и сохранённый на Hub roster с этим учеником. Подробности и проверка: [mail-api-deployment.md](mail-api-deployment.md).

Пароль даёт доступ к API входящих KIBERone. Это не SMTP/IMAP-пароль: исходящая почта и вход сторонним почтовым клиентом не реализованы. Учётные данные сервер хранит в `mail-accounts` с Unix-правами 0700/0600. В локальной сети используется существующая модель доверия Tutor/Student; выбор имени ученика не является отдельной защищённой аутентификацией.

## VPN Tutor

Экран управляет установленной службой `WireGuardTunnel$<имя>`. По умолчанию имя `KIBERoneTutor`. Профиль и права запуска/остановки службы нужно установить заранее; интерфейс не поднимает UAC. Проверка соединения и реальные переключения VPN на рабочем ПК не выполнялись. Автоматический выбор региона и проверка внешнего IP пока не перенесены из демонстрационного макета. На macOS экран сообщает об управлении через WireGuard.

## Проверка

Сборки Tutor, Student и Hub проходят. 136 тестов проходят, включая стабильность пароля ящика, отказ при чужом пароле, чтение MIME-письма, нормализацию сайтов и сохранение правил при переносе roster. В Student через интерфейс проверены вход в класс, открытие почты, сообщение об отсутствующем пароле локации и загрузка каталога приложений. Автоматизация окна Tutor заблокирована ошибкой идентификатора приложения в computer-use; визуальная проверка его новых экранов остаётся незавершённой.

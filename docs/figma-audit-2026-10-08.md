| Раздел | Состояние |
| --- | --- |
| Класс, экраны, ученики и группы | Основные действия реализованы. Макет содержит демонстрационные данные и упрощённую навигацию. |
| Уроки печати | Каталог, редактор, назначение, результаты и статистика реализованы. Личные рекорды после 100 правильных символов сохраняются локально и синхронизируются через центральный сервер по ID ученика. После входа на другом ПК подтягиваются лучшие скорость и точность; без интернета локальная копия сохраняется до следующей попытки. Достижение цели не завершает попытку, завершает конец текста или кнопка. |
| Викторины | Каталог викторин в три колонки с изменением, запуском всей викторины, импортом и созданием. Общая библиотека доступна всем локациям через кнопки «С сервера» и «Опубликовать». Чужие документы редактируются как копии, публикации проверяют ревизии. Вопросы переключаются после ответов или истечения времени; прогресс восстанавливается после перезапуска тьютора. Примеры карточек Figma — демонстрационные, приложение показывает реально сохранённые документы. |
| Почта | Реализованы автоматическая выдача, повторные попытки, копирование адреса/пароля, HTML-письма, изображения и ссылки, удаление через 24 часа. Сервисы и форма добавления удалены из макета вслед за приложением. Не реализованы отправка писем, IMAP и скачивание вложений. |
| Смена ученика | Реализованы локальная копия изменённых файлов, попытка синхронизации и очистка почты/результатов в интерфейсе. Макет ведёт на выбор ученика; промежуточное ожидание сохранения ещё не представлено отдельным экраном. |
| Сохранения | Снимки проекта сохранены. Добавлены настоящие Git-коммиты, ветки, переключение, восстановление, слияние и diff через встроенный LibGit2Sharp. Установка Git на ПК не требуется. При конфликте слияния файлы остаются на месте; автоматического разрешения конфликтов нет. История хранится у тьютора в .history/git для папки ученика/модуля, без центрального Git-хостинга. |
| Доступ класса | Правила общие для группы. Каталог приложений ограничен App Paths и запущенными программами. Сайты контролируются через Chrome/Edge; другие браузеры не покрыты. |
| VPN тьютора | Управление предварительно установленным подключением по имени. Автовыбор страны, внешний IP и расширенная диагностика из прежней концепции не реализованы; макет приведён к существующему интерфейсу. VPN на рабочем ПК не запускался. |
| Настройки | Пароль локации сохраняется один раз после успешной проверки. Визуальные переходы и состояния прототипа в Figma не везде соответствуют анимациям Avalonia. |

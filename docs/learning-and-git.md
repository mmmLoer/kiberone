# Викторины, рекорды и история проектов

Тьютор использует пароль локации, сохранённый при настройке. Центральный адрес — `MailServerUrl`, по умолчанию `https://nshub.pro/`; транспорт требует HTTPS.

## Викторины

В разделе «Викторины» выберите «С сервера». Библиотека общая для всех локаций; загруженные документы доступны без интернета. «Изменить» чужую викторину создаёт локальную копию. Сохранённые викторины хранятся отдельно от серверного кэша. «Опубликовать» сохраняет документ на сервере; обновить существующий документ может только его локация, с проверкой ревизии.

«Запустить викторину» отправляет весь набор подключённым ученикам. Следующий вопрос появляется после всех ответов или окончания времени. Ученики видят номер вопроса; завершение закрывает викторину. Прогресс хранится рядом с БД тьютора (`<database>.quiz-runs`), после перезапуска текущий вопрос повторно доставляется с прежним ID. Уже принятый ответ повторно XP не начисляет.

## Рекорды

Порог — 100 правильных символов. Лучшие скорость и точность объединяются независимо и никогда не уменьшаются. Ключ урока — SHA256 имени и текста урока; одинаковое содержимое на разных ПК имеет общий ключ. После heartbeat ученика агент синхронизирует рекорды раз в 15 секунд и перед сменой ученика. При отсутствии сервера рекорды остаются локально. Старые записи с ключом ID урока переносятся при открытии соответствующего урока.

Сервер принимает записи только для ученика в авторизованной локации; локальный API определяет ученика из привязки клиентского заголовка. Файлы расположены в `/var/lib/kiberone-hub/learning/records-<studentId>.json`.

## Git

«Сохранения» → выбрать ученика → «Загрузить файлы» → «История проекта и ветки». Можно сравнить сохранение с предыдущим, создать ветку, перейти в неё, объединить её с текущей или вернуть сохранение. Перед изменением файлы сохраняются; результат передаётся ученику через обычную синхронизацию, включая удаления. При конфликте слияние отменяется: сравните версии и исправьте файл вручную.

Репозиторий Git хранится у тьютора в папке проекта `.history/git`, текущая ветка — `.history/git-branch.txt`. Git встроен через LibGit2Sharp 0.32.0; в Windows-дистрибутив обязательно входит native `git2-*.dll`. `.git`, `.history`, окружения Python и node_modules не включаются в историю. Это локальная история у тьютора, без remote/push и центрального Git-хостинга. Просмотр показывает до 100 последних коммитов; старые коммиты не удаляются. Diff ограничен 200000 символами.

## Проверка

```powershell
dotnet test tests/Kiberone.Tests/Kiberone.Tests.csproj --filter "FullyQualifiedName!~Vpn"
```

VPN этим тестовым запуском не включается.

Центральные API: POST `/api/learning/quizzes/list`, `/api/learning/quizzes/publish`, `/api/learning/records`. У каждого запрос содержит пароль локации; не записывайте тела запросов в логи. Ограничение тела — 1 MiB, отдельный nginx rate limit 20 запросов/с на IP с burst 100. Почтовые ограничения сохранены отдельно.

# KIBERone Classroom — handoff для следующего агента

Актуально на 3 октября 2026 года. Документ описывает фактическое состояние ветки `main` после работы предыдущего агента. Пароли, токены, SSH-ключи и другие секреты здесь намеренно не записаны.

## Коротко о продукте

KIBERone Classroom — локальная система для компьютерного класса:

- Tutor запускается на компьютере преподавателя, хранит базу и поднимает локальный HTTP API.
- Student запускается на Windows-компьютерах учеников, автоматически находит Tutor в LAN, получает команды и отправляет телеметрию.
- Основной сценарий рассчитан на работу внутри одной локальной сети даже при плохом или заблокированном интернете.
- Дополнительно есть Hub для централизованных данных и обновлений, а также Windows VPN-компоненты.

Репозиторий: `https://github.com/mmmLoer/kiberone`.

Текущая ветка: `main`.

Текущий HEAD: `531eda0` (`Ship 0.10.37: enlarge the student typing trainer and fix lesson save`).

Каноническая версия приложения: `BuildInfo.Version` в `src/Kiberone.Core/ClassroomNetwork.cs`, сейчас `0.10.37`.

## Основной runtime-поток

1. Tutor стартует и создаёт локальную SQLite-базу.
2. Tutor поднимает HTTP API на TCP `8765`.
3. Tutor объявляет себя через UDP discovery: запрос `8766`, beacon `8767`.
4. Student находит Tutor, получает sync token из discovery и подключается.
5. Student отправляет heartbeat примерно каждые 3 секунды.
6. Tutor кладёт команды в надёжную очередь; Student получает их через HTTP/WebSocket и подтверждает ACK.
7. Tutor считает Student offline примерно после 15 секунд без heartbeat.

Удалённого shell нет. Student выполняет только разрешённые `ClassroomCommandKinds`.

## Данные Tutor

Главный каталог:

- Windows: `%LOCALAPPDATA%\KIBERone Classroom`
- macOS: `~/Library/Application Support/KIBERone Classroom`

Основные файлы и папки:

- `classroom.db` — SQLite.
- `sync-token.txt` — токен Student API.
- `tutor-token.txt` — токен привилегированных Tutor API.
- `server-id.txt` — постоянный ID Tutor.
- `sync/` — сохранения учеников и версии файлов.
- `starter-pack/` — раздаваемые файлы/папки.
- `wallpaper/` — текущие обои класса.
- `screens/` — последние превью экранов учеников.
- `tutor-crash.log` — ошибки Tutor.

Отдельные пользовательские настройки Tutor находятся в `KIBERone/Tutor/settings.json` внутри LocalApplicationData. Квизы — в `KIBERone/Tutor/quizzes`.

Эти данные не хранятся в git. Перед переустановкой Tutor их нужно резервировать отдельно.

### Режим фокуса

- В настройках Tutor можно указать части заголовков окон через `;`.
- Этот список уходит Student вместе с командой focus.
- Если поле пустое, используется встроенный список: Roblox, Poki, Yandex Games, Minecraft, Steam и т. п.

### Синхронизация файлов ученика

Новая модель:

- На ПК ученика рабочая папка плоская: `Рабочий стол/Имя Фамилия`.
- Подпапки `1 модуль`, `2 модуль` и т. п. на Student не создаются.
- Tutor хранит файлы по структуре группы/ученика/активного модуля.
- При смене активного модуля содержимое локальной рабочей папки заменяется файлами нового модуля.
- Старые модульные папки исключаются из сканирования; legacy-папку текущего модуля код умеет поднять в корень рабочей папки.
- Удаления и конфликтные изменения могут требовать подтверждения Tutor.

Главные файлы: `FileSyncService.cs`, `StudentFileSyncClient.cs`, `StudentAgent.cs`, `FileSyncModels.cs`.

## Сеть и MikroTik

Последняя рабочая схема класса:

- Локальная сеть класса: `192.168.31.0/24`.
- MikroTik: `192.168.31.1`.
- Tutor и Student должны находиться внутри этой сети.
- Wi-Fi класса: `KiberOne` на 5 ГГц.
- Uplink: WISP через отдельное 2.4 ГГц радио к внешней точке.
- Класс изолирован firewall-правилами от LAN внешнего роутера.
- TCP `8765` — Tutor HTTP API.
- UDP `8766/8767` — discovery.
- TCP `9777` — опциональный VPN Agent.

Пароли Wi-Fi, WISP и RouterOS в документ не включены. Их нужно получить у владельца проекта. Административный пароль RouterOS следует проверить и при необходимости сменить.

Последняя проверка MikroTik при 4 Wi-Fi-клиентах показывала около 4% CPU и примерно 190 МБ свободной памяти из 256 МБ. Для класса из 12 учеников + Tutor аппаратного ресурса достаточно; вероятное узкое место — 2.4 ГГц WISP uplink, а не локальная сеть KiberOne.

## Известные несоответствия и технический долг

1. `README.md` устарел: показывает версию 0.2.0 и называет реализованные функции будущими этапами.
2. `Directory.Build.props` содержит `<Version>0.8.0</Version>`, тогда как продуктовая версия берётся из `BuildInfo.Version` и installer-файлов.
3. Версия дублируется в `BuildInfo.Version`, `scripts/build-installers.ps1` и трёх `.iss`; при релизе нужно менять все значения синхронно.
4. `Tutor/ViewModels/MainViewModel.cs` и `Tutor/Views/MainWindow.axaml` очень крупные и отвечают за много несвязанных разделов.
5. Навигация Tutor всё ещё опирается на исторические индексы 0–18.
6. Database evolution сделан через `EnsureCreated` + ручные SQL `ALTER TABLE`, а не EF migrations. Новые изменения схемы должны учитывать повторный запуск и старые базы.
7. Для полного теста Student UI нужен Windows-компьютер. macOS подтверждает только Tutor и кросс-компиляцию.
8. Тексты песни в репозитории отсутствуют; в трёх уроках стоят подсказки-заглушки.
9. Focus mode закрывает окна по фрагменту title, поэтому браузерная вкладка блокируется только если запрещённое слово видно в заголовке окна.
10. Старые Student-сборки не понимают multi-answer quiz, плоскую структуру сохранений и новые focus-настройки — Student нужно обновлять вместе с Tutor.
11. `.DS_Store` сейчас остаётся незакоммиченным; его не следует добавлять в git.

## Практический порядок продолжения

1. Перед изменениями проверить `git status` и `BuildInfo.Version`.
2. Не трогать пользовательские данные в LocalApplicationData без резервной копии.
3. При изменении DTO сохранять совместимость старого Student или явно поднимать версию и обновлять клиентские ПК.
4. Для схемы БД делать повторно исполняемые upgrade-шаги и проверять работу на существующей `classroom.db`.
5. После правок Student собрать Windows-версию и проверить реальный сценарий на отдельном Windows-ПК.
6. После правок Tutor пересобрать `dist/KIBERone Tutor.app` по macOS-инструкции.
7. Перед push не добавлять `dist`, `bin`, `obj`, `.DS_Store`, токены, location secrets и router credentials.
